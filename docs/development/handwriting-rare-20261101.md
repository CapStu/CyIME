# 中文手写：生僻字模板（2026-11-01）

用户反馈：「很多人用手写就是写生僻字的」「有的生僻字必须手写，拼音拼不出来」。

## 问题

内置模型 ochwpro（`eb04d62a…`）的字表是 CASIA 联机单字库的 7356 类（汉字 7185 + 符号 171）：
GB2312 全有，通用规范汉字表（rime-ice 8105 表）缺 1126 个（犇 垚 燚 叕 圐 圙…），扩展A 一个没有。
和拼音比：拼音（8105 + 生僻字开关的 41448 表）能出、手写出不了的字约 19,000 个；反过来 0 个。
字表里没有的字，模型怎么微调都认不出。

## 做法

不重训模型。和日语字表外的漢字一样，给生僻字做笔顺模板，写的时候把模型输出当特征和模板比：

- 收字：8105 与 41448 表里基本平面（含扩展A）的汉字，去掉模型已有的，再去掉表外的繁体写法（說 照旧出 说）。共 16252 个，有模板 16176 个。
- 笔顺：Make Me a Hanzi、AnimCJK 有的直接用（1862 字）；其余按 cjkvi-ids 的结构（⿰⿱⿸…）用部件拼，版面和部件在该位置的写法取自 Make Me a Hanzi 里同结构的字，每字拼 3 种。共 44804 个模板。
- 特征：模型前 320 类概率开方归一化（与假名模板一致）；模板只存最大的 32 项，4.4 MB（zip 后约 3.7 MB）。
- 查询只比首位类在查询前 32 类里的模板（平均约 400 个）。
- 排序（`HandwritingCandidatePolicy.mergeRare`）：模板分 = 0.5 × 相似度²，相似度低于 0.6 不出，最多 4 个；
  和模型候选一起按常用度重排后仍排第一的放最前，其余排在模型前 3 个之后。分数按原位置保留，叠写切分不变。
- 模型哈希不对（换了别的模型）时不用；个人模型是在内置模型上微调的，照用。

生成：`tools/handwriting_training/build_rare_hanzi.py`，所需公开数据和下载地址见脚本说明。

## 离线回放（电脑上同源 ONNX，按 App 逻辑读生成的文件）

| 检查 | 结果 |
|---|---|
| 标准笔迹 1500 字（GB2312 一级，抖动） | 首选变 1 个，首选准确率 98.1% → 98.1%；前五含正确字 1498 → 1496 |
| 个人样本 170 字 | 首选变 0 个，88.2% → 88.2%；前五 162 → 161 |
| 常用字前三出现生僻字 | 1500 字里 1 次，170 字里 0 次 |
| 有真笔顺的生僻字 800 个（抖动） | 首选 20.2%，前五 88.8% |
| 只有拼出来模板的生僻字（只在生僻字之间比，留一法） | 首选 84%，前五 94% |
| 拼出来的笔顺直接给模型认（模型字表里的 1483 字） | 首选 85%（真笔顺 97%） |

生僻字多数排第四、五位：首选让给常用字是有意的（常用字首选不能变）。
真人写生僻字的准确率没有测过（没有真人生僻字样本），未验收。
