# 1.15.34 词库加载修复验收

## 故障与覆盖升级

三星 SM-X800 的临时 Android 用户保留了一份同时启用个人短语与分类词库的旧配置。1.15.24 在键盘上反复显示 `Duplicate key 'engine/translators/+'. It was previously given at line 2, column 3.` 及「30 秒后自动重试」。第二张反馈截图仅显示向导「准备中」，没有足够信息将其归于同一个原因。

用独立包名的诊断实例保留原始错误数据覆盖升级，1.15.34 在 37 秒时显示「已就绪」。逐键输入 `ceshi` 上屏了旧个人短语「验收短语」，随后 `nihao` 上屏了「你好」。迁移生成的备份与原始配置逐字节相同，个人短语文件的 SHA-256 在升级前后相同，用户配置 `menu/page_size` 仍在。诊断实例只改安装清单及签名，另用真实签名轻量版在系统「备份与恢复」导入同一配置后覆盖升级，两次输入均进入编辑框。

## 验证范围

- 79 项相关单测通过，覆盖个人短语与分类词库的两种配置顺序、旧重复键、保留自定义翻译器、可选英文候选失败后的回退等。
- 对比 1.15.33 与 1.15.34 轻量版内 13 个原生库和 166 个 Rime 配置、字典及资源成员，逐个解压计算 SHA-256，179 项一致。此检查不代表逐机型的打字速度测量。
- 升级与首装均在三星平板临时用户中完成。捕获的 UI、输入框读回值、配置前后哈希及安装包回执保存在 `D:/CyIME-Data/eval/translator-retry-20261101/`。平板日常用户的数据不用于构造故障。
