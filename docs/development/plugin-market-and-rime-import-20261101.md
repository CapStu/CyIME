# 插件市场与 Rime 文件导入

「设置 → 扩展 → 插件」先显示随包目录，再按 `xime_index.base_urls` 刷新远程目录。AI 翻译、AI 帮写、AI 智能回复和输入统计保存在 `store/plugins`，四个可选包共 14,544 字节。安装前核对 SHA-256、清单 ID、版本和宿主版本。新装的市场插件默认关闭，用户在「已安装」启用并配置。现有文件导入、联网授权和内置在线语音沿用原入口。远程目录随仓库发布，本批本地检查使用随包副本。

目录维护者修改 `plugins/<名称>/` 下的源码和插件版本后，可运行 `python scripts/build-plugin-market.py` 重建目录和版本化的包。收录 API 插件前用插件运行时的模拟服务核对工具面板和返回结果；本次没有使用个人密钥连接第三方服务。

旧导入路径会让同秒选择的多个包共用一个暂存目录。单独选择方案文件时，还会在读取方案声明前覆盖同名文件，并根据文件名启用方案。现在设置页和系统分享都让单个方案、词库与压缩包使用相同的文件冲突检查，每个包独立暂存。安装器先核对根目录方案声明和文件名，错误提示指出具体文件。本地导入列出缺少的直接引用，不自动下载依赖。是否编译成功仍以「应用方案更改」的部署结果为准。

依赖扫描器取冒号后整段文字的做法来自 6 月 6 日，同秒导入编号来自 7 月 12 日。这两段实现早于本批修改。[依赖扫描器历史](https://github.com/Cyletix/CyIME/commit/b3be1eb79d7ec93935bc41b1ce735b43bfc099ec) · [导入编号历史](https://github.com/Cyletix/CyIME/commit/0da8e8646e2d8d04b8759c1304d983189593c5c7)

用上游薄荷全拼原文件检查时，旧依赖扫描把 `dictionary` 和 `dependencies` 行尾的说明读成了文件名的一部分，也把带注释的空词典名当作引用。现在这些值按 YAML 规则读取。该文件没有声明输入语言；语音和手写的语言选择是独立问题。此处只核对原方案定义，未使用反馈者的配置部署整套薄荷。[薄荷全拼方案（固定版本）](https://github.com/Mintimate/oh-my-rime/blob/cb4f7dda2fb74332cda0a7712ffc89ea5ded856f/rime_mint.schema.yaml)

- **虎码。** 用户给的是虎码官方下载网盘。其「03 虎码输入法下载 → 其它码表包」中的 `虎码官方版2026_08_15.7z` 同时包含 Rime、Fcitx、QQ 五笔等目录。给 CyIME 的 ZIP 选取 `publish/rime` 下的虎码单字、小词库两份方案、四份词典和作者的方案顺序，复用 CyIME 自带的拼音反查及符号文件。电脑同源引擎输入 `zhh`，两个方案都以「虎」为首选。字集过滤选项在该引擎有兼容提示，本次没有验证全部反查和筛选功能。[虎码官方下载目录](https://huma.ysepan.com/#/)
- **万象。** 官方 v18.1.8 Base 包直接包含 10 份方案。导入时按原包 `default.yaml` 指定的顺序取 `wanxiang`，保留本机设置。语法模型另行提供；电脑复用已有的 409,412,652 字节 LTS 文件，用同源引擎部署全拼，`nihao` 首选「你好」。九键替换旧模型时，用户导入的语法文件和外部方案仍在使用的语法文件都应保留。[万象发布页](https://github.com/amzxyz/rime-wanxiang/releases/tag/v18.1.8) · [官方安卓安装说明](https://amzxyz.github.io/rime-wanxiang/doc/trime.html)
- **水杉。** 水杉有自己的输入引擎。其应用安装程序、方案配置与 Rime 方案分别处理。可迁移词表的范围取决于导出格式和编码。[水杉官方常见问题](https://msime.app/faq/)
