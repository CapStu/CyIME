# 1.15.32 输入缺陷复现与验证

## 已定位的三处缺陷

- **键盘弹出时抛空区间异常。** 把 [#42](https://github.com/Cyletix/CyIME/issues/42) 报告的 432 dpi 换算为密度 2.7。在 1080 × 2400 窗口中，构造顶部为 2110 和 2107 px 的键盘面板，旧公式算出两组反向区间，分别为 `2131.6001 > 2131.5999` 和 `2128.6 > 2128.5999`。原逻辑用不同顺序求菜单高度和窗口坐标，菜单填满可用高度时舍入差异会让 `coerceIn` 抛异常。改为在同一个内边距矩形中计算尺寸和可移动距离，最后平移到窗口。新增回归核对两处面板位置、满高菜单和横向边界。三星平板设为相同分辨率和密度时，旧版也能显示键盘，现场复现来自报告坐标的回归用例。
- **Android 13 长按地球键闪退。** 用真实语言键 Compose 组件长按，在 Robolectric API 33 的旧代码中抛出 `NoSuchMethodError: ViewTreeObserver.addOnWindowVisibilityChangeListener`。该方法从 API 34 提供，原分支误写为 API 33。现从 API 34 启用监听，旧版本继续使用已有的可见性检测。相同测试在 API 29、33、34 均能打开菜单。[#39 原报告](https://github.com/Cyletix/CyIME/issues/39)没有附栈，荣耀 X30 与鸿蒙 Mate 20 Pro 原机仍待验收。[Android 方法文档](https://developer.android.com/reference/android/view/ViewTreeObserver#addOnWindowVisibilityChangeListener(android.view.ViewTreeObserver.OnWindowVisibilityChangeListener))
- **同一次长按删完拼音后继续删除正文。** 三星平板用 1.15.24 完整版的独立测试实例，在编辑框写入 `123456` 并输入未上屏的 `ni`，按住删除 1.55 秒后六个数字全部消失。现在一次持续按压一旦处理了输入法内的编码或候选，就会在越过正文边界时停止。九键向通用退格路径交接时保留同一次按压的状态。抬手后再次按删除可以操作正文。范围仅为 [#33](https://github.com/Cyletix/CyIME/issues/33) 的长按误删，重复显示编码与 [#12](https://github.com/Cyletix/CyIME/issues/12) 一起跟踪。

## 尚未定案的复现

- **首次部署。** [#36](https://github.com/Cyletix/CyIME/issues/36) 来自荣耀 X30、Android 13、1.15.24。为保留平板现有应用及词库，分别用已核对发布哈希的 1.15.24 轻量、完整 APK，修改清单内包名和关联标识并以测试密钥重签。核对所有其他载荷条目与原包一致。在 SM-X800、Android 14 上用两个全新 UID 和空私有数据，各自启用并设为输入法后，均从「准备中」进入「已就绪」。两份首次部署日志已保存。此结果不能关单，也没有据此修改部署流程。
- **点选候选偶尔未上屏。** [#40](https://github.com/Cyletix/CyIME/issues/40) 的原环境是荣耀 GT Pro、Android 16、小鹤双拼。平板的独立 1.15.24 完整版用小鹤双拼 26 键输入 `ni`，第二候选「尼」点选后升为首选，编辑框逐步收到 12 个「尼」。用户反馈的间歇性漏提交通路未复现。在原有候选过期记录之外，增加编辑框拒绝提交的日志，保留待重试的候选；该日志不写输入内容。
- **快速同键和折叠屏。** [#31](https://github.com/Cyletix/CyIME/issues/31) 已有英文字母连按实机记录，详见[气泡与快速双击](mobile-feedback-20261101.md#点按气泡与快速双击)。原小米中文、日语 26 键仍待复测。[#37](https://github.com/Cyletix/CyIME/issues/37) 的内外屏宽度存储有单元测试，缺 OPPO Find N3 实际折叠切换。

## 语音标点评审

[PR #22](https://github.com/Cyletix/CyIME/pull/22) 的评审版本为 `9f8f7532e9c34fa7b1ec8fa6437227cd730fd64b`。在线成功时标记接口原文可保留标点，在线失败走本地回退时清除该标记，总开关关闭时走原有空格化规则。与当前主目录合入时，需保留已有的逗号、句号等分项设置。补丁在语音处理、设置界面、搜索与会话测试处已有上下文冲突。

在独立 JVM 中编译上述版本的语音代码与对应测试，复用主目录的 debug 测试依赖。在线后端标点、识别收尾和多语言会话三个测试类共 77 项通过，在线请求使用本机模拟接口。

还有一种待覆盖的录音场景：同一录音切换识别段时，管理器拼接前段文本和新段文本，却只传出拼接后的字符串；界面按最近一次结果的标点标志处理整段。混合来源的两段可以有不同的标点能力，需按段保留来源再验证。未合入此 PR。[PR #23](https://github.com/Cyletix/CyIME/pull/23) 与 [PR #24](https://github.com/Cyletix/CyIME/pull/24) 仍按原顺序暂缓评审。
