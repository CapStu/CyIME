# 固定候选（2026-11-04）

用户报告（Windows 版，手机同样）：`oned` 首选是「欧奈尔的」，OneDrive 一直排第三。要求：除了忘掉，还能手动把词固定到前面；固定多个按先后排；能取消。

## 长按候选卡片（改后全部功能）

- 引擎候选（候选栏和展开页）：标题是「词」，按钮 取消 / 固定（已固定时是「取消固定」）/ 忘掉。
  - 固定：这个编码下排第一，固定多个按固定的先后排。
  - 取消固定：回到原来的位置。
  - 忘掉：和以前一样，删掉学习记录，词库里本来有的词回到原位，自造词消失（固定不受影响）。
  - 取消、点卡片外面：关掉卡片，什么都不改。
- 没在组词时（联想）或引擎正忙拿不到状态：不显示固定按钮，卡片和以前一样（标题「忘掉学习」）。
- 手写候选：不变，只有忘掉笔迹。
- 插件注入、不在引擎菜单里的词：点固定提示「「词」不能固定」，不改别的。

## 做法

- 共用代码 `app/src/main/jni/librime_jni/candidate_pins.*`，与 Windows 版 `third_party/cyime-engine/policy/candidate_pins.*` 同一份。
- 编码：当前正在打的那一段输入，去掉 `'` 和空格（九键是数字串，14 键是合并键码）。同一编码固定多个，先固定的排前面；别的编码不受影响。
- 只能固定菜单里本来就有的词，不凭空加词；在前 200 个候选里找，找到就挪到最前，原位置不再重复出现。
- librime 补丁（`patches/cyime-librime.patch` = `app/src/main/jni/cmake/RimeDictionary.patch`）在 `InitializeComponents` 里把 `cyime_pins` 过滤器接在每个方案自己的过滤器后面：所有方案生效，不改方案文件、不改 `.custom.yaml`。没有固定时过滤器不包装菜单。
- 存储：Rime 用户目录 `cyime_pins.txt`，一行一条 `编码<TAB>词<TAB>固定时间(Unix 秒)`，`#` 开头是注释，读不懂的行原样保留；文件存在但读不了时不覆盖。两端同一格式，以后同步可直接合并。
- 没有设置开关：不长按就没有任何变化，也没有额外开销。
