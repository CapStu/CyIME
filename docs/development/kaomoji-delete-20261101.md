# 颜文字面板退格验收

三星 SM-X800 使用 CyIME 设置里的输入测试框及设置搜索框，逐项点按和长按屏幕实际按键。1.15.35 输入 `QAo:-)` 后长按删除 1.45 秒，编辑框读回 `QAo:-`。

第一份测试包能整删一枚颜文字，连续插入的两枚也可分次删除。发现切去 Emoji 再切回时，控件遗失了插入顺序，导致 `QAo:-)` 被当成以 `o:-)` 结尾而误删了正文的 `o`。1.15.37 将记录保存在当前输入会话中，并对可能属于前一个词的字母前缀作保守处理。按住只触发一次。宿主编辑框按当前选区和光标附近实际文本确认，键盘内部编辑框使用对应编辑器的选区。

逐项检查了 572 个内置颜文字、长短重叠、单词词尾、残缺文本和无匹配。测试日志、修复前后的截图与实际编辑框读回值保存在 `D:/CyIME-Data/eval/kaomoji-delete-20261101/`。
